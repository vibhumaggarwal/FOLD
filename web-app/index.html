How FOLD works

FOLD performs pure, lossless client-side steganography. It reads the raw bytes of your file, appends an integrity header (CRC32), and converts every bit into black & white pixels.

These pixels are arranged into 128x128 grid frames using 4x4 blocks to survive video compression. The frames are immediately captured via MediaRecorder and exported as a WebM video.

When decoding, FOLD reads each frame using requestVideoFrameCallback, extracts the embedded sequence indices to avoid duplicate frames, validates the checksum, and triggers a download of the original intact file.
